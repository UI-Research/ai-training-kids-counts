# Installing R and RStudio

R is an open source statistical programming language. RStudio is an Integrated Development
Environment (IDE) for developing R code. RStudio is developed by the for-profit company
Posit. Don’t worry, you don’t need to pay any money for this software.

## Windows
### R

1) Navigate to the CRAN website.
2) Click “Download R for Windows”
3) Click “base”
4) Click “Download R 4.5.1 for Windows”
5) Follow the installation instructions. Accept all defaults and install R.

### RStudio

1) Navigate to the RStudio website.
2) Download the RStudio Desktop installer for Windows. It should be something similar
to “RStudio-2025.05.1-513.exe”.
3) Follow the installation instructions. Accept all defaults and install RStudio.
4) Open RStudio. If successful, then R and RStudio are installed.

## Mac
### R

1) Navigate to the CRAN website.
2) Click “Download R for (Mac) OS X”
3) Select the .pkg link under “Latest Release” that corresponds with your chip type (Apple
silicon or Intel).
4) Follow the installation instructions. Accept all defaults and install R.

### RStudio
1) Navigate to the RStudio website.
2) Download the RStudio Desktop installer. It should be something similar to “RStudio-
2025.05.1-513.dmg”.
3) Follow the installation instructions. Accept all defaults and install RStudio.
4) Open RStudio. If successful, then R and RStudio are installed.
